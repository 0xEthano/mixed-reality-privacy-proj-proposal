# Eight-week project timeline

Weeks are relative to the start date

| Week | Work | Milestone / output | Responsibility |
| ---- | ---- | ------------------ | -------------- |
| 1 | Review literature; catalog pose, gaze, and gesture candidates; set up the environment and project organization | Literature matrix, access checklist, workstation plan | Ethan: setup and organization; both: research; Avaneesh: literature and dataset review |
| 2 | Inspect accessible samples, terms, IDs, and labels; choose scope and split policy; coordinate authorized dataset access | Dataset selection gate; final experiment plan; access barriers recorded | Ethan: transfer and access workflow; Avaneesh: dataset selection and split protocol; both: methods review |
| 3 | Validate and preprocess data; audit missingness and units; construct split manifests | Data quality summary and reproducible preprocessing | Both: software and Python pipeline; Avaneesh: split protocol design |
| 4 | Extract features; implement identification baselines | Validation results and leakage review | Avaneesh: features and model design; both: implementation and methods review |
| 5 | Analyze supported behavior; compare sensor subsets | Behavior baseline or documented exploratory analysis | Avaneesh: analysis and evaluation design; both: implementation and results review |
| 6 | Evaluate normalization and other privacy transformations; run sensitivity checks | Privacy–utility comparison; optional Unity replay only if time permits | Avaneesh: experiment design; both: Python pipeline, optional Unity replay, and results review |
| 7 | Freeze configurations; run held-out tests; quantify uncertainty; draft report | Aggregate metrics, figures, limitations, report draft | Both: software, experiments, and review; Avaneesh: evaluation design; Ethan: report creation and integration |
| 8 | Review reproducibility and evidence; finalize report and presentation | Final project package and contribution statement | Ethan: report/presentation creation and milestone tracking; both: final methods and results review |
